# 개인정보 점검과 데이터 처리

공개 대상은 소스, 합성 테스트, 문서, 아이콘과 그 라이선스, 설치 스크립트 및 앱 번들입니다.

- 실제 인증 파일·키체인 데이터·계정 ID·이메일·대화 로그·로컬 DB를 포함하지 않습니다.
- 사용자 폴더는 실행 중 macOS API에서 구합니다. 개발자의 홈 경로를 하드코딩하지 않습니다.
- 앱은 인증을 각 제공자의 한도 조회에만 사용하며 인증 원문·응답 원문을 저장하거나 출력하지 않습니다.
- UserDefaults의 설정은 사용자 Mac에만 저장되며 앱 번들에 들어가지 않습니다.
- 기본 Claude 프로필의 키체인은 사용자가 연결을 요청할 때만 읽고, 자동·일반 새로고침에서는 메모리의 인증정보를 사용합니다. 만료·접근 거부 시 자동으로 키체인을 재조회하지 않습니다.
- 릴리스 ZIP은 Finder 메타데이터·확장 속성을 포함하지 않습니다.
- 개발자 경로, 이메일, 토큰 패턴과 개인 키를 `python3 Scripts/privacy-audit.py`로 검사합니다. 패턴 검사는 모든 비밀을 탐지한다고 보장할 수 없으므로 공개 대상 파일을 함께 검토합니다.

공개 GitHub 계정명과 저장소 주소는 프로젝트 소유자 식별을 위해 포함됩니다. 아이콘 라이선스에는 원저작자 고지가 포함됩니다.

## 공개 전 검증 결과 (2026-10-29)

소스·문서와 릴리스 ZIP의 개인 홈 경로·이메일·토큰·개인 키 패턴 검사에서 발견된 항목이 없습니다. 실제 로컬 Codex 로그인 토큰·계정 식별자와의 메모리 내 정확 일치 검사에서도 일치 항목이 없었습니다. 검사에 사용한 실제 값은 보고서나 파일에 기록하지 않았습니다.

체크섬·서명 확인 후 신규 설치와 기존 버전 백업 설치를 시험했고, 손상된 ZIP이 설치 전에 거부되는 것을 확인했습니다. 커밋 작성자 이메일에는 공개 GitHub noreply 주소를 사용합니다.
